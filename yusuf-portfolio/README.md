# Omotosho Yusuf — Professional Portfolio

Responsive single-page portfolio for an AI Data Annotator and Yoruba Language Specialist.

## Preview locally
1. Install Node.js.
2. Open this folder in a terminal.
3. Run `npm install` then `npm run dev`.

## Deploy on Vercel
1. Upload this folder's contents to a new GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Use build command `npm run build` and output directory `dist` (Vercel should detect Vite).
4. Select **Deploy**.

## Before publishing
Please verify your Outlier task details, ND institution/date and all experience details. This version avoids naming customer-support employers because dates in previous CV versions have not yet been reconciled.
